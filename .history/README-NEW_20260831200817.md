## 💡 Overview

**NoteMind AI** is a full-stack intelligent notes platform that automatically enriches your notes with AI-generated summaries, tags, and study flashcards. Built with **Spring Boot 4.0**, **PostgreSQL**, and **Redis**.

### Key Features

🤖 **AI-Powered**
- Automatic summaries (SHORT, DETAILED, BULLET_POINTS)
- AI-extracted tags from note content
- AI-generated Q&A flashcards for active recall

🔍 **Smart Search**
- Full-text search across titles, content, and summaries
- PostgreSQL `tsvector` with GIN indexing
- Ranked results by relevance

📁 **Organization**
- User-scoped folders
- Multimodal attachments (images + text)
- Nested note retrieval

🔐 **Secure**
- JWT authentication with refresh tokens
- BCrypt password hashing
- User data isolation
- 15-minute access tokens, 7-day refresh tokens

⚡ **Performance**
- Redis caching layer
- Automatic cache invalidation
- Connection pooling
- Optimized database queries

## 🚀 Quick Start

```bash
# 1. Clone
git clone https://github.com/sukhmmeet/NoteMind-AI.git
cd NoteMind-AI/backend

# 2. Set environment variables
export DB_URL="jdbc:postgresql://localhost:5432/notemind_ai"
export JWT_SECRET_KEY="your-256-bit-secret-key"
export GOOGLE_API_KEY="AIza..."

# 3. Start services (PostgreSQL & Redis must be running)
./gradlew bootRun

# 4. Test
curl http://localhost:8080/api/v1/auth/signup
```

## 📡 API Overview

**Base URL:** `http://localhost:8080/api/v1`

**Main Endpoints:**

| Category | Examples |
|---|---|
| **Auth** | POST `/auth/signup`, `/auth/login`, `/auth/refresh-token`, `/auth/logout` |
| **Notes** | POST `/notes`, GET `/notes`, GET `/notes/{id}`, PUT `/notes/{id}`, DELETE `/notes/{id}`, GET `/notes/search?query=...` |
| **Flashcards** | POST `/notes/{id}/flashcards/generate`, GET `/notes/{id}/flashcards`, PATCH `/flashcards/{id}` |
| **Folders** | POST `/folder`, GET `/folder`, PATCH `/folder/{id}`, DELETE `/folder/{id}` |

**Authentication:** All endpoints (except `/auth/signup` and `/auth/login`) require:
```
Authorization: Bearer <your-jwt-token>
```

## 🏗️ Architecture

```
REST Controllers → Services → Repositories → PostgreSQL + Redis
         ↓
   JWT Authentication → Authorization → User Scoping
         ↓
   External APIs → Google Gemini, OpenRouter, Cloudinary
```

**Layered design:**
- **Controllers** - REST endpoints at `/api/v1/*`
- **Services** - Business logic & AI integration
- **Repositories** - JPA data access
- **Security** - JWT tokens & user isolation
- **Caching** - Redis for performance

## 🔐 Security Highlights

- **Password:** BCrypt hashing (strength 10)
- **Tokens:** HMAC-SHA256 signed with 256-bit key
- **Access tokens:** 15-minute expiry
- **Refresh tokens:** 7-day expiry with revocation support
- **User scoping:** All queries filtered by authenticated user
- **Input validation:** All DTOs validated with `@Valid`
- **SQL injection:** JPA parameterized queries only
- **HTTPS ready:** SSL/TLS configuration included

## 🐛 Common Issues

**Issue:** PostgreSQL connection refused
```bash
brew services start postgresql  # macOS
sudo systemctl start postgresql # Linux
```

**Issue:** Redis connection refused
```bash
brew services start redis       # macOS
sudo systemctl start redis-server # Linux
```

**Issue:** JWT token expired
```bash
# Get new token using refresh token
curl -X POST http://localhost:8080/api/v1/auth/refresh-token \
  -H "Content-Type: application/json" \
  -d '{"refreshToken": "your-token"}'
```
